# Гималайский кашемир — MAX Mini App

Готовая стартовая версия интернет-магазина для MAX: каталог, фильтр, корзина, оформление заказа, MAX Bridge и серверная отправка заказа владельцу через MAX Bot API.

## Запуск
1. Установите Node.js 20+.
2. `npm install`
3. Скопируйте `.env.example` в `.env`.
4. Для локального демо можно оставить MAX_BOT_TOKEN и ADMIN_MAX_USER_ID пустыми: заказ будет выводиться в консоль сервера.
5. `npm start`
6. Откройте `http://localhost:3000`.

## Подключение к MAX
1. Верифицируйте профиль бизнеса/ИП/самозанятого в MAX для партнёров.
2. Создайте чат-бота и получите токен.
3. Разместите проект на HTTPS-хостинге.
4. В панели бота: Расширенные настройки → URL мини-приложения → укажите HTTPS URL.
5. Запишите токен только в серверную переменную `MAX_BOT_TOKEN` — никогда не добавляйте его в public/app.js.
6. В `ADMIN_MAX_USER_ID` укажите MAX user_id владельца, которому будут приходить заказы.

## Каталог
Меняется в `public/products.json`. Для каждого товара: `id`, `name`, `category`, `price`, `description`, `image`, `available`.
